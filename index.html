IVFEngine: A Deep Learning Based Live Baby Birth Prediction System

IVFEngine (In Vitro Fertilization Engine) is an interpretable deep learning model that uses clinical parameters from IVF treatment cycles to predict live baby birth outcomes using the FT-Transformer architecture.

Our platform provides accurate predictions to assist clinicians and researchers in reproductive medicine.
